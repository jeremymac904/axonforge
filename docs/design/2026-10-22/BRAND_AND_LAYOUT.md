# Axon Forge Labs brand specification

October 22, 2026. Approved visual direction; implementation reference.

## Selected direction

Jeremy selected concept 1, originally named Ember & Steel, with orange replaced by navy blue. Retain the cinematic metal AF sculpture, clear sans-serif hierarchy, dark graphite surfaces, metallic silver highlights, spacious scrolling composition and strong section structure.

This specific decision applies to Axon Forge Labs and its AxonBotOS platform. It does not replace other platform identities or Jeremy's separate mortgage/social branding.

## Logo, typography and icons

Use the angular AF mark and Axon Forge Labs wordmark from the selected image as the production design reference. The large sculptural version is appropriate for the homepage; header/footer and product usage need simplified readable variants. The PNG mockup is not an original vector logo. Prepare SVG, transparent PNG, favicon, monochrome and small-size variants as separate production assets.

Use clean, bold sans-serif headings with readable body copy. Inter or Geist is a proposed implementation family, subject to existing repository fonts and licensing. The generated image does not establish an exact font file. Use a consistent outline icon set and real approved product assets.

## Palette

Navy, charcoal, metallic silver and white are the selected palette. [design-tokens.json](design-tokens.json) provides proposed implementation values, not measured samples or an accessibility certification. Avoid orange as the brand accent. Brighter steel-blue illumination may be used sparingly in artwork; controls should remain restrained navy with adequate contrast.

The website selection is a dark homepage. Only AxonBotOS has an explicitly approved light-mode layout in this session. A website light theme would require its own design work.

## Homepage structure

1. Hero and two primary actions.
2. Selected platforms with truthful availability.
3. AI Briefing editorial area.
4. Practical tutorials.
5. Founder introduction.
6. Clearly labeled AI collaborators directed by Jeremy.
7. Contact invitation and support/policy footer.

Use actual final content in implementation. Product visuals and editorial cards in the concept are illustrative. Keep the approved layout while replacing mock content with real assets and working destinations.

## Implementation acceptance

Verify readable typography, semantic headings, alt text, keyboard access, contrast, responsive layouts, reduced-motion behavior, image performance and working links/forms in the built candidate. The mockup is appearance evidence only. Preserve current working code, routes and owners; no runtime change or deployment is made by this documentation package.
